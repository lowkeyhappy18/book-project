Chapter 2: Number System

A number system is a method of representing numbers using a specific set of symbols and rules. In computer science, number systems are important because computers understand and process data in digital form. The commonly used number systems are decimal, binary, octal and hexadecimal. The decimal number system uses ten digits from 0 to 9, whereas the binary number system uses only two digits, 0 and 1. The octal system uses digits from 0 to 7, and the hexadecimal system uses sixteen symbols, from 0 to 9 and A to F. Each number system has a particular base or radix.

Number system conversion is the process of changing a number from one number system into another. Decimal numbers can be converted into binary, octal or hexadecimal numbers, and numbers from these systems can also be converted back into decimal. Binary numbers are especially important in computers because electronic circuits work using two states, represented by 0 and 1. Understanding number systems and their conversion helps us understand how computers represent, store and process data internally.
