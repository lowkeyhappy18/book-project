Chapter 6: Web Technology I

Web technology refers to the tools and technologies used to create, develop and access websites and web applications through the Internet. Web development involves creating and organizing content that can be viewed using web browsers. Web browsers are software applications used to access and display websites, while search engines help users find information available on the Internet. Various Internet and web technologies have made communication, information sharing, education, business and online services easier and more efficient.

HTML, or HyperText Markup Language, is the standard markup language used to create and structure web pages. It uses tags and attributes to define elements such as headings, paragraphs, links, tables, forms, images, audio and video. CSS, or Cascading Style Sheets, is used to control the appearance and presentation of web pages, including their fonts, colors, backgrounds and layout. Together, HTML and CSS provide the basic foundation for designing and developing attractive and organized websites.
